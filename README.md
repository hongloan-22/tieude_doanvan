# Bài thực hành HTML: Tiêu đề và đoạn văn

## Nội dung
- `index.html`: sử dụng thẻ `<h1>`, `<h2>` và hai thẻ `<p>` theo yêu cầu bài tập.

## Cách xem
Mở file `index.html` bằng trình duyệt Chrome hoặc Microsoft Edge.

## Đưa lên GitHub
1. Tạo repository mới trên GitHub.
2. Đặt tên ví dụ: `bai-tap-tieu-de-doan-van-html`.
3. Tải `index.html` lên repository hoặc dùng Git để commit và push.
